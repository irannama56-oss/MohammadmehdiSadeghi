## Multiple image variants for the resume picture

User asked for "another image with quality quality quality". Built
3 additional PNG variants at different DPI / aspect ratios, all from
the same `resume.html` source:

| File | Dimensions | DPI | Size | Use case |
|---|---|---|---|---|
| `resume-image-ULTRA-3x.png` | **2724×5532** | 3× | 4.1 MB | Print master, A3-scale |
| `resume-preview-900.png` | 1800×3552 | 2× | 1.7 MB | 2× master |
| `resume-image-A4.png` | 1374×2664 | 1.5× | 798 KB | A4 print |
| `resume-image-IG-4x5.png` | 1242×2688 | 1.5× | 705 KB | IG portrait (tall) |
| `resume-image-IG-square.png` | 1242×1010 | 1.5× | 477 KB | IG landscape banner (hero only) |

Generation recipe (Playwright + headless Chrome at system Chrome path,
no agent-browser dependency since playwright-cli wasn't installed and
agent-browser daemon kept crashing):

```python
page = browser.new_page(
    viewport={"width": 960, "height": 1900},
    device_scale_factor=3.0,   # the quality knob
)
page.goto(URL, wait_until="networkidle")
page.wait_for_timeout(800)
elem = page.query_selector(".page")
bb = elem.bounding_box()
page.screenshot(path=OUT, clip={
    "x": bb["x"] - 4, "y": bb["y"] - 4,
    "width": bb["width"] + 8, "height": bb["height"] + 8,
})
```

The `device_scale_factor` is what determines quality — 3× renders
each CSS pixel as 3 physical pixels, so a 900-wide CSS page renders
to 2724 actual pixels. For 4× DPI (3500+ wide), Playwright + system
Chrome works; would need `device_scale_factor=4` but file size
quadruples.

The `clip` rectangle (with 4px bleed) avoids the body padding
showing in the image — captures only the `.page` element.

**Gotcha**: the `.page` width is locked at 900px via the resume's
own CSS, so all variants share the same layout proportions. The
aspect ratio comes out to ~1:2.03 (very tall portrait) — perfect for
A4/Letter print, less ideal for IG feed (4:5 = 1:1.25). For a true
IG square (1:1), the hero card alone is 900×665 (landscape), so it
needs a reflowed layout that I deferred — easier to just crop the
ULTRA at the photo+name section.
